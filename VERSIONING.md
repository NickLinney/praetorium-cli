# Versioning

Praetorium follows SemVer with project lifecycle phases:

- Pre-alpha snapshots: `0.0.0-pre-alpha.N`.
- Alpha releases: `0.MINOR.0-alpha`.
- Beta releases: `0.MINOR.0-beta`.
- Release candidates: `MAJOR.MINOR.PATCH-rc.N`.
- Stable releases: `MAJOR.MINOR.PATCH`.

Pre-alpha tags are immutable feature-complete snapshots for their declared scope. Version changes require a release note, changelog entry, and annotated tag.
